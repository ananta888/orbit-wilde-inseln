# Original test assets

These tiny glTF files are generated by `tests/assets/fixtures.py` and licensed under the repository's BSD-3-Clause license. `triangle.glb` is a single indexed triangle. `animated-morph.glb` adds one skin joint, a rotation clip and a morph target. They exercise data preservation, not artwork quality.

License-policy tests attach fictional CC metadata to fixture uploads. This test metadata describes simulated provider responses, not the actual license of these repository files. No third-party assets are included here.
